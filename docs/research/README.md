# 上游规格提取稿（独立实现证据链）

本目录保存两份**只记录领域规格、不复制实现代码**的提取稿：

| 文件 | 上游 | 提取内容 |
|---|---|---|
| `openbidkit-spec.md` | `FB208/OpenBidKit_Yibiao`（AGPL-3.0） | 数据字段口径、核对规则、阈值、导出流程 |
| `zhibiao-spec.md` | `fb-labs/ZhiBiao`（AGPL-3.0） | 解析/台账/大纲/生成链路行为、评分与检查规则 |

## 使用与留存

- 两份文档均为人工阅读上游源码后写下的**行为描述**，含 `文件:行号` 引用以便复核，
  正文不含上游源码片段，也不含可直接编译/运行的移植代码。
- BidCraft 的实现（`bidcraft/`）是独立编写的 Python 代码；规则以 YAML 规则包
  （`bidcraft/resources/packages/*.yaml`）重新表达。
- 本目录与 git 历史共同构成「独立实现」的证据链，**请勿删除或改写历史记录**。
  如后续需要补充上游信息，请新增文件，不要覆盖既有提取稿。
