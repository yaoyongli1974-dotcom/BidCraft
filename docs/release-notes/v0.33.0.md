# v0.33.0 发版说明（AI 可靠性与实战效果专项改造）

本版本从 v0.32.2 稳定基线 `7fe741dcc7c066e9b77e1269fae3260f7894e389` 出发，在 `fix/v0.33.0-rc-reliability` 分支完成 RC-01～RC-13 全量专项改造。重点是 AI 工具链可信执行、章节规划与知识资产生命周期一致性、生成/退款并发可靠性、检索与质量评估的未测量口径，以及真实件 E2E 数据门禁。历史迁移 `0001`–`0012` 零改动，Alembic 单 head 保持 `0015_fact_confirmation`，导出门禁与风险复核门禁未削弱。

## 1. 工具链可靠性与 Agent 安全

- 工具结果验证区分「结构化证据」「业务失败」与「纯文本未验证」；必需工具必须有已验证轨迹，且同一工具出现失败轨迹即不通过。
- 工具参数/结果统一脱敏；工具循环支持 `max_seconds`、`fail_on_tool_error`、同轮去重，所有调用带真实审计 ID 与调用关联 ID。
- 服务端工具策略覆盖预算/严格模式/去重；写操作统一执行项目权限与待审批门禁；`TechnicalAgent` 把真实 `ModelClient` usage 写入结果。
- 新增 `GET /agents/{agent_type}/tools` 与前端工具轨迹展示，避免 mock 成功冒充真实执行。

## 2. 章节规划与知识资产一致性

- 已确认规划依赖评分项、需求、事实、知识文档和章节标题的实时值；任一依赖变化即追加中文校验说明并判废，旧版本不再被回退复用。
- 同步生成冻结已门禁的规划身份；`regenerate` 参数生效，包件范围和人工调整文本正确进入规划上下文。
- 知识文档内容变化后撤销已发布/复核状态并清理发布标记；检索与向量构建只使用可发布文档，企业匹配同样遵守生命周期门禁；删除文档/知识库时清理查重引用。

## 3. 生成并发与账务单一归属

- 退款由 marker 与 Job 两套幂等账本统一归属：先到者写入 `refunded` / `refund_source` 并关闭另一账本，reaper、TTL 对账、worker 失败路径不会再退第二笔。
- 失败关闭统一走条件状态转换；`_fail_job()` 返回竞态结果，取消陈旧任务时不再重复入队；失败后释放持久化 `GenerationLease`。
- 章节失败写入改为 fencing 短事务钩子，长生成 Session 不再直接覆盖章节状态；`force=True` 不覆盖 confirmed/locked 章节。
- 心跳允许连续三次瞬态失败后才中止；PostgreSQL claim 使用 `FOR UPDATE SKIP LOCKED`，SQLite 行为不变。

## 4. 检索、质量、经验与审批

- 新增纯函数检索基准：Recall@5/10、Precision@5、MRR、NDCG@10 及来源完整率、越权率、无效资产率、降级率；真实 qrels 缺失时全部为 `None` 且 `measured=false`。
- 新增专家评分校准：Pearson/Spearman、Brier 与分箱校准；样本不足或零方差一律未测量，不伪造相关系数。
- 经验治理支持项目级策略、等级/可信度/过期/撤销；过期或撤销的经验不会进入 prompt；撤销只写项目 meta 与审计，不改写源证据。
- 审批规则新增逐条件解释：字段名、操作符、期望值、实际值、是否命中、缺失数据；商务审批链路补齐报价摘要数值字段，前端优先展示后端解释。

## 5. 真实件与过程指标口径

- 真实/脱敏投标 E2E 由数据集清单驱动：解析→大纲→生成→检查→导出，并校验标注条款、取值与判定；无真实数据集时显式“数据阻塞”跳过，绝不用合成件替代。
- 清单校验全文件扫描合成标记，并要求 `source=user-provided`；CI 打印 DATA BLOCKED / READY，但不把数据阻塞计为失败。
- 过程指标新增逐项 `measured`：零分母或采集失败显示“未测量”，前端不再把缺失数据渲染为 0.0%。
- 质量 summary 补齐 `ref/name/report_version/created_at` 与未测量 stub；Markdown 导出与前端面板同步“未测量”口径。
