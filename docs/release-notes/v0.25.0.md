# BidCraft v0.25.0（对标易标 · 第二批）

本版完成对标易标专项改造的**第二批**：企业知识库 2.0（含企业共享）、商务标自动编制、多维查重，三块一次性发布。第一批（v0.24.0）的评分覆盖矩阵与 DOCX 引擎继续保留。

## 本版内容

### 1. 企业知识库 2.0 + 企业共享

- **企业/组织实体**：新增 `Enterprise` / `EnterpriseMember`，owner 管理成员、member 只读共享资产、非成员不可见（404，不泄露存在性）。
- **文档级知识库**：新增 `KbDocument`，`KbChunk` 加 `document_id/page_no/heading/chunk_index/hash`；按 sha256 增量索引（内容未变不重建），检索结果带文档 ID / 页码 / 标题。
- **企业共享资产**：资质、人员、业绩（`Qualification.kind='performance'`）新增 `enterprise_id`（NULL=owner 私有，向后兼容；非 NULL=企业成员共享）。过期资质、在建锁定人员不得作为有效匹配；名称相近只记候选、不自动满足。
- **注销/导出适配**：账号注销时移除企业成员关系、共享资产移交企业 owner；账号导出增加企业字段。
- **联合检索修复**：生成时个人库之外追加当前用户可访问的企业库，且不再排除全局库（延续第一批修复）。

### 2. 商务标自动编制

- **确定性汇编器**：投标函、开标一览表、分项报价、资格响应、业绩、人员、商务偏离表——全部来自事实台账 / 已审批报价 / 企业资质人员，**缺失写 `{{待填:...}}`，不编造**。
- **定稿报价口径**：只从 `status='approved'` 的 `BoqQuoteVersion` 取价；未指定版本取该包件最新 approved；显式未审批或无 approved 版本时 `ready=False` 并阻断，不用活动快照充当定稿。
- **一致性校验**：金额 / 税率 / 币种 / 包件与引用版本漂移、报价已变更仍引用旧版本，都能检出。
- **状态机与审批**：draft→submitted→approved/rejected，复用 `boq.normalize_chain/applicable_stages/completed_stages`（owner/admin 或当前级链审批人可审批，重复会签被拒）。
- **导出**：XLSX 8 工作表（含版本名 / 审批人 / 审批时间）、DOCX 合订本；导出走统一 `export_gate` 硬门禁。

### 3. 多维查重

- **四维独立**：文本（复用 `dedup` 内核）/ 结构（标题与章节顺序）/ 语义（复用 embedding，模型不可用回退文本并标 `degraded`）/ 图片（字节哈希 + dHash，Pillow 可选，缺失降级 sha256）。
- **报告与命中落库**：`SimilarityReport` / `SimilarityHit`，命中带来源 / 定位 / 原文摘录；复核 pending/confirmed/ignored；Markdown 报告导出。
- **保守原则**：法规 / 国标 / 招标原文 / 合同固定条款 / 企业统一声明标记为合理重复候选而非删除；图片相似只输出候选，不直接认定抄袭；查重全程只读章节正文。
- **权限**：跨项目比对校验 `source_project_id` 权限；发起 / 复核要求写权限，读接口要求项目可见。

### 4. 前端

新增企业、商务标、查重三个工作台 tab 与对应 API 模块 / 组件 / 路由；商务标明确「无已审批报价版本不得定稿」引导；查重四维筛选、双栏摘录、人工复核与报告导出。资质页轻量增加企业视图筛选（不重写）。

## 兼容性与边界

- **数据库**：新增 6 张表（`enterprises`/`enterprise_members`/`kb_documents`/`similarity_reports`/`similarity_hits`/`commercial_docs`）+ 既有表可空列（`Qualification.enterprise_id`/`Personnel.enterprise_id`/`KbChunk` 五列）。Alembic revision `0005_yibiao_batch2`，幂等升级、**downgrade 可执行**（先删索引再删列）。原有 owner 私有语义默认不变。
- **对外 API**：仅新增端点，未改既有响应结构；三域路径纳入认证前缀白名单。
- **降级说明**：查重未接 jobqueue（同步执行返回 202 + report_id，业务逻辑在 service 层，后续可迁 runner）；图片 Pillow 可选；语义模型不可用回退文本查重。
- **归属边界**：企业 owner 注销且无其他成员时企业容器被删除（避免 FK 悬挂）——若产品要求长期保留无 owner 企业，需另定义归属，当前未实现。
