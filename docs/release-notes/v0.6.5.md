# BidCraft v0.6.5

修掉两个会静默放行的判定问题：素材有效期按服务器本地日期算、以及类型未知的素材被当成可信。

## 修复

- **有效期按北京时间日历日判定**：此前用 `date.today()` 取服务器本地日期，「今天到期」在不同
  时区/不同宿主上会漂一天。现引入 `bidcraft/clock.py`（`BEIJING_TZ = UTC+8`）作为时间口径的
  唯一入口，证书/业绩等有效期的过期判定统一走北京日历日。
- **素材类型未知或缺失 → 失败关闭**：未注册的 `kind`、或 YAML 里根本没写 `kind` 的材料，此前
  会被当作「无规则约束」注入正文。现在一律不注入，宁可少一条素材，也不让来源不明的材料进标书。
- **CI：客户端发布改为仅手动触发**：`desktop-release.yml` 去掉 tag 触发，服务端打 tag 不再连带
  构建桌面客户端。
- 补边界用例：到期当天、前一天、跨时区机器上的判定结果一致。

## 验证

- 后端：全量 pytest 通过（含 `tests/test_material_policy.py` 新增边界），ruff 全绿。

## 说明

桌面客户端已归档，本版仅服务端；不提供桌面安装包。
