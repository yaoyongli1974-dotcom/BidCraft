# BidCraft v0.6.6

把「时间」这件事一次性收口：全仓排查谁还在用本地日期、谁输出的时间戳不带时区偏移。

## 本版内容

- **对账单按北京日归档与格式化**：账单周期、日汇总的边界与展示都走北京日历日，不再随服务器
  时区漂移；跨月/跨年的边界用例补齐。
- **DOCX 封面日期**：导出的封面日期取北京日期，与对账单、有效期判定同源。
- **9 处对外 payload 补齐时区偏移**：接口返回的时间戳统一带偏移量（而不是裸的本地时间字符串），
  前端/客户端无需猜测时区。
- **文件名口径统一**：导出与备份文件名中的日期部分统一为北京日期。
- **源级护栏**：新增 `tests/test_clock.py`，除行为用例外还扫描源码，阻止再次引入
  `date.today()` / 裸 `datetime.now()` 这类绕过 `clock.py` 的写法。
- 涉及模块：`accounts`、`api`、`billing`、`boq`、`cli`、`clock`、`compliance`、
  `export/docx`、`personnel`、`qualifications`、`terms`。

## 验证

- 后端：全量 pytest 通过（含新增时区用例），ruff 全绿。
