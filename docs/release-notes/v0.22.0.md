# BidCraft v0.22.0

这一版把判定引擎从「能跑」推进到「可量化验证」：修复复合条款绕过截止日期校验的问题，建立业绩证据归属，统一日期精度规则，并新增判定质量回归集与假接受率（FAR）度量。核心标准是——每一条招标要求都能拆分、识别、关联、比较和举证，任何已知不满足的实质性条款不得被错误放行。

## 本版内容（R08–R15）

- **R08 复合条款完整校验**：把最终判定逻辑抽成统一的 `_decide()`，整条与每个原子共用。此前复合条款（多原子）判定汇总后提前返回，绕过了业绩截止日期校验块——本版让截止日期校验下沉到每个原子，复合条款不再绕过。汇总时保留原子级 `deadline_window` 证据。
- **R09 拆分歧义识别**：把「出现连接词」与「拆分有歧义」分离。并列连接词切出带独立约束的原子视为干净拆分；只有转折词（但须/但/然而/除外/另有）才标歧义。共同修饰同一主体的补充描述（如「具有一级资质并保持有效」）不再被机械拆成两条。atom_id 稳定、原文偏移精确。
- **R10 业绩证据归属**：新增 `PerformanceEvidence` 结构（项目名/类型/签订·开工·竣工·验收日期/精度/来源），按项目名与类型匹配、同项目多证明去重，合同签订日不再当竣工日，项目类型无法可靠匹配转人工复核。
- **R11 约束主体局部定位**：局部窗口改为标点+连接词双重边界，解决无标点复合子句（「业绩且带宽≥1000Mbps」）主体串味；主备链路限定词参与归因。
- **R12 日期精度与日历边界**：日期精度分 year/month/day，不把年份臆造成 1 月 1 日；月份回退用真实日历（含闰年、月末、大小月）；年份精度边界、未来日期、非法日期转人工复核；日期类型（签订/开工/竣工/验收）区分。
- **R13 单位规则回归**：补齐 KHz/km/m/s/min/day 等单位并登记量纲，中文「两」识别、浮点比较容差 1e-9、单位注册表自检（已注册单位必须可被提取）。
- **R14 判定质量回归体系**：新建 `bidcraft/calibration.py` 与 `tests/fixtures/verdict_regression.json`（16 条样本，覆盖资质/业绩/数量/金额/带宽/存储/质保/响应/交付/否定/复合/单位换算），输出混淆矩阵与假接受率，CI 纳入回归集；标准答案变更需人工审核。
- **R15 导出与人工复核闭环**：正文修改后自动使本章已确认的条款响应失效（退回 pending、清空确认快照与章节锚点、写入审计），确保「确认的是 A 版、导出的是 B 版」不再发生。HTTP/MCP/CLI/批量/ZIP 共用同一门禁，强制导出独立权限 + 完整审计（含被越过条款原判定），门禁失败不产生成功审计。
