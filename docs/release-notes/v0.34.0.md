# BidCraft v0.34.0 发版说明

主题：**商业化安全、账务一致性与生产可靠性专项收口**

## 1. 支付回调安全

- 微信支付回调新增签名时间戳新鲜度（±300 秒）、平台证书序列号、签名类型校验。
- 解密前校验事件类型、资源算法，显式捕获 `InvalidTag`。
- 解密后强校验 mchid / appid / 订单号 / 交易号 / 交易状态 / 币种 / 正整数金额。
- 回调 body 限制 1 MiB；非 SUCCESS 状态安全 ACK，不入账。
- mock-pay 仅允许模拟渠道订单，防止临时开关下零成本支付真实订单。

## 2. 资金一致性与原子抢占

- `mark_paid` 与 `redeem` 改为数据库条件 UPDATE 抢占，只有胜者入账。
- 新增迁移 `0017_transaction_id_unique`：非空交易号部分唯一索引，历史重复 fail-closed。
- 配置校验拒绝非法数值与重复套餐 ID；营收统计仅计真实微信渠道净额。
- 全量资金路径仍保持 marker / job 单一退款所有权。

## 3. 任务退款、租约与 DB 并发

- `_fail_job` 先抢 failed 状态，再由胜者退款；并发失败不再双退款或双事件。
- requeue / startup 清理过期 `generation_lease_token`，worker 自动重取租约。
- 退款加锁顺序统一为 `job → marker → user`；失败退款有界自动补偿。
- 审批链改为条件 UPDATE + 快照重算，避免并发会签互相覆盖。
- 同步生成增加逐章 lease/abort 门禁。

## 4. 文件完整性、权限与审计

- 上传改为临时文件 + 事务成功后替换，失败清理孤儿文件。
- 新增迁移 `0018_file_checksums`：用户文档和资质证据记录 sha256。
- 上传 magic byte 白名单；下载时校验路径和 checksum。
- 共享资质移交同步搬移证据文件；用户注销清理私有证据。
- 模型配置、计费设置、兑换码、管理员调整点数等补齐审计。
- `/admin/health` 的 `web_ready` 路径修正。
- 对账单 CSV 增加金额 / 点数 / 状态 / 交易号 / 渠道列。

## 5. 备份、前端与 CI

- `pg_dump` 使用 `--single-transaction`；备份 manifest 记录 DB / secret key 哈希；校验失败关闭。
- `watchJob` 终态与后端一致并在终态停止轮询；BillingPage 终态停止轮询并防重复提交。
- `AdminHealthTab` 修正 `workers_running` 语义。
- CI 保持 9 个 job 和强制门禁，新增 PG 并发测试、`/health/ready` 冒烟、非阻断恢复演练状态输出。

## 6. 兼容性

- 新增迁移：`0017_transaction_id_unique`、`0018_file_checksums`，均幂等可逆。
- API 路由数不变；前端契约不变；导出门禁与业务规则未放宽。
- SQLite 与 PostgreSQL 兼容；历史空交易号允许共存。

## 8. 边界与已知限制

- 真实生产 PostgreSQL / PgBouncer、Docker 运行时、生产备份恢复演练需远程 CI 或用户环境验证。
- 历史文件没有 checksum 时跳过校验；旧证据占位符保留纯文本回退。
- 远程 CI 对最终 SHA 的结果必须在合并 main 前单独确认。
- 本版本不包含远程插件市场、容器级隔离或真实招标文件样本。
