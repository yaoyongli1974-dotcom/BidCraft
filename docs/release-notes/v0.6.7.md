# BidCraft v0.6.7

堵住素材可信度的最后一道免检通道，并把桌面客户端的归档决定写进仓库。

## 修复

- **`other` 不再是免检通道**：此前素材类型选 `other` 就能绕过所有字段校验直接进正文。现在
  `other` 必须提供 `source_url`（可追溯出处），否则不注入。
- **写入侧素材类型必填**：创建/更新素材时 `kind` 不能再缺省为 `other`，避免「不知道是什么」
  被当成一种合法类型沉淀下来。
- **前端不再默认 `other`**：素材录入表单不再预选 `other`，必须显式选择类型。

## 文档

- **桌面客户端归档声明**：README 定位、安装、部署、文档索引、MVP 表，以及 `docs/roadmap.md`
  与 `docs/desktop.md` 顶部，均写明「冻结于 v0.6.3，不再更新」。
- **`LICENSE`/`NOTICE` 补 LGPL 义务**：新增桌面端小节，说明 PySide6/shiboken6/Qt 6 为
  `LGPL-3.0-only OR GPL-2.0/3.0`、Qt WebEngine 内含 Chromium 等各自许可、QtPy MIT、
  pywebview BSD-3-Clause、PyInstaller GPL-2.0-or-later + bootloader 例外；并列出自建或再分发
  时的 5 条义务（动态链接不静态合并、随附 LGPL 文本与可替换说明、修改 Qt 须开源、
  WebEngine 第三方义务、商业许可可豁免）。
- `docs/desktop.md` 注明 v0.6.3 的 4 个安装包已撤下。

## 验证

- 后端：全量 pytest 通过，ruff 全绿；前端：lint 0 errors / 0 warnings，`134 tests` 通过。

## 说明

桌面客户端已归档，本版仅服务端；不提供桌面安装包。
