# v0.31.0 发版说明

**主题：并发可靠性、账务一致性与真实投标质量治理**

本版本在 v0.30.0 质量治理基础上，聚焦「任务被抢占时不能写脏终态」「扣费与退款在并发和崩溃下必须对得上」「真实件质量口径必须可测且未测量时必须明示」三条主线。全部改动在独立分支 `quality/v0.31.0-reliability` 上按阶段提交，未推送 main、未创建 Release、未变更生产配置。

## 1. Worker fencing 原子化（阶段 1）

- 新增 `jobqueue.commit_fenced_result(job_id)`：把 fencing 条件 UPDATE（status=running + token 匹配 + 租约未过期）与业务写入放在**同一个事务**；PostgreSQL 行锁 / SQLite 单写事务，无 PG 专用语法。
- 查重任务拆成「纯计算会话」+「一次 fenced 提交」；旧命中先删后写，done 报告仍幂等复用；多次 100 轮并发验证无重复提交。

## 2. JobQueue 状态机与 Reaper 并发（阶段 2）

- `VALID_TRANSITIONS` + `transition_job()`：一条条件 UPDATE 完成状态迁移，支持 token、租约过期阈值、attempts 上限、清理认领字段；终态不可变。
- `_requeue()` 返回 `requeued|failed|lost`，竞争失败的 reaper 不再伪造失败事件；心跳不再给过期租约续命，异常时置 abort。50 轮双回收压测通过。

## 3. 账务一致性与同项目生成互斥（阶段 3）

- 异步生成现在也有 `PendingCharge` marker，note 与 Job id 双向关联；退款按 `done_steps` 的实际章节数，不再用项目级差值；付款账号优先用 `billing_account_id`，子账号删除后仍可退款；负 TTL 直接拒绝。
- 用户批准业务规则 **A：禁止同项目并发生成**。新增 `GenerationLease`（项目主键 + token + 心跳 + 过期时间）与 Alembic `0012_generation_lease`；同步/异步三条生成入口统一在扣费前抢占租约，冲突返回 409，成功/失败/异常释放，worker 心跳续租、终态释放。两线程并发验证只有一单扣费、一个 Job。
- `_cancel_stale_jobs()` 既有语义未改。

## 4. 全 Worker 可靠性矩阵（阶段 4）

- 新增 `finalize_job_result()`，8 个 worker 的终态写入（含 generation 的 marker 结算）全部改为事务级 fencing；中止统一走 `JobAborted`，不写 failed、不退款。
- `tests/test_worker_reliability_matrix.py` 静态核对 8 个 worker 的 fencing/abort 检查点，并动态验证失效 token 不产生部分写入。

## 5. 真实件数据集与质量指标（阶段 5、6）

- 新增 `tests/fixtures/tender_real/` 数据集契约：manifest schema、sha256、脱敏标记、路径安全、重复检查；真实样本与 `dataset.json` 被 `.gitignore` 排除，仓库只交付 `README.md` + `dataset.example.json`。
- 新增 `evaluation/tender_quality.py`：真实件条款召回率、关键值解析率宏平均；`verdict_agreement` 在缺少标注应答时保持 `null`。数据集未就绪时状态为「未测量」，全部比率为 `null` 并附原因，绝不把未测量写成 0。
- 质量报告摘要新增 `tender_quality`，与既有人工修改率/问题密度/清单匹配率并存。

## 6. 前端质量闭环与运维（阶段 7、8）

- 质量评估页新增「过程与真实件指标」面板，6 项指标统一展示；未测量显示「未测量」，比率按百分比、问题密度按「/千词」格式化。
- 新增 `docs/operations/BIDCRAFT_DATABASE_BACKUP_RESTORE.md`：备份内容、manifest/SHA-256、SQLite/PG 恢复步骤、迁移前 preflight、演练与留痕口径。

## 7. 兼容性

- 新增迁移 `0012_generation_lease`（可逆、幂等保护）；历史迁移 0001～0011 未修改。
- 成功响应体与既有 API 业务语义不变；唯一新增行为是同项目并发生成的 409。
- 数据库兼容 SQLite 与 PostgreSQL；未连接生产库测试。

## 8. 验证

- 后端全量：`1669 passed, 18 skipped, 1 warning in 750.77s`，零失败。
- 前端：39 files / 320 tests，typecheck / lint / build 均通过。
- ruff check 与 `git diff --check` 通过；历史迁移 diff 为 0；`tests/` 与 `web/src/` 无删除文件。
- 备份恢复演练 `BIDCRAFT_RESTORE_DRILL=1` 通过。

## 9. 边界与后续

- 真实招标文件与人工标注需用户提供；在此之前真实件指标为「未测量」，不能用合成夹具替代。
- 远端市场自动安装、容器/系统级隔离、质量报告导出与批量看板仍按既有决策暂缓。
- 本版本仅完成代码与本地验证；是否合并 main / 发布由用户另行决定。
