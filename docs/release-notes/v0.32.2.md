# v0.32.2 发版说明（AI 技术标编制引擎闭环与审批规则收口）

本版本从稳定基线 v0.31.3（`883a679`）出发，在分支 `feature/v0.32-ai-engine` 上一次性收口三段工作：v0.32.0 AI 技术标编制引擎升级、v0.32.1 报价审批链规则命中条件、v0.32.2 质量评估概览前端闭环。v0.32.0/v0.32.1 未单独打 tag，本版作为首个 v0.32.x 正式版本。所有 API 路由数 274、Pydantic 请求模型 93、Alembic 单 head `0015_fact_confirmation`，历史迁移 `0001`–`0012` 零改动，导出门禁与风险复核门禁均未削弱。

## 1. 章节规划引擎

- 新增可版本化、可确认、可追溯的章节规划实体与 Alembic `0013_chapter_planning`；状态机覆盖未创建、生成中、草稿、待复核、已确认、已用于生成、重生成、更新与驳回。
- 评分点、需求、事实、知识、章节引用一律校验真实项目范围内 ID；模型编造的 ID 被丢弃并写入 `validation_errors`，个人知识库不进入规划上下文。
- 规划状态与生成门禁、prompt、Job payload、章节提交联动；默认 review 模式要求人工确认，`review_strict` 可禁止无规划章节生成，auto 模式仅告警。
- 新增规划生成/重生成/编辑/确认/历史查询等 7 条路由，前端在 OutlineTab/DraftTab 提供规划面板与状态展示。

## 2. 知识资产引擎

- 新增 Alembic `0014_kb_asset_metadata`：文档级结构化状态、复核人/时间、发布/驳回信息、来源文件关联与同库重复候选表。
- 文档可提炼为结构化资产并保留块级溯源；资产状态机为草稿、复核、批准、发布、驳回、归档；legacy `NULL` 状态沿用既有检索行为。
- 管理端与企业端各 5 条资产路由（提炼、列表、复核、查重候选、处置），企业端按企业可见性与 owner 权限控制并写审计。
- 前端管理端/企业端提供资产审核、状态流转、溯源与重复候选面板；无 mock 成功即闭环。

## 3. 混合检索与生成治理

- 检索 Passage 携带真实 chunk/document/page/heading/trace，RRF 重排、按库归一化、时效与就绪度参与排序；知识上下文保留 rerank、可信分级、降级与未知信号（未知保持 `null`，不伪造为可信或 0）。
- 生成规划上下文改用项目/包件范围限定的真实 provider 引用，编造引用被丢弃；worker 使用 Job 中快照并二次校验，确认状态、租约、章节提交与溯源刷新在同一 fencing 事务内完成。
- 项目侧新增只读检索预览；导出门禁识别陈旧章节并阻止交付，强制导出仍需 owner 与不少于 4 字原因且审计留痕。

## 4. Agent 工具闭环

- 新增轻量工具循环，复用既有 MCP/registry 唯一工具系统；每轮工具调用记录名称、参数、结果摘要、验证状态、审计 ID、耗时与错误标记。
- 服务端工具策略按 agent 配置，用户请求的工具键不能越权；内置 MCP 工具与插件调用执行项目权限校验、可审计、可验证；WorkflowTask 与 run 结果持久化工具轨迹。
- 新增按 agent 类型的工具目录路由；前端 AgentsTab 展示可展开的工具调用轨迹，刷新后仍保留真实审计证据。

## 5. 经验回流、事实治理与质量评估

- 新增只读经验回流：来自已处置质量问题、人工修订、审批/强制导出审计与规划历史的建议以 ADVISORY 文本进入 prompt，不自动写入知识库或企业资产。
- Alembic `0015_fact_confirmation` 为事实增加可空确认人/确认时间；服务端盖章、来源与引文校验、覆盖保护、值变更失效联动与专项审计齐全。
- 质量评估纳入真实规划覆盖、检索降级/低可信/缺溯源、事实确认、工具审计失败等证据；零分母指标标记 `measured=false`，跨报告问题密度按稳定键去重。
- 新增质量报告 Markdown 导出与跨项目只读汇总；`QualityTab` 展示跨版本评估概览，未测量项显示“未测量”，不伪造分数、等级或结论。

## 6. 报价审批链规则（v0.32.1）

- 审批阶段可追加最多 20 条 AND 规则，字段为 `total_amount`、`package_id`、`currency`、`boq_rows`、`priced`、`unpriced`、`match_rate`，操作符为 `gte/lte/eq/ne/in/not_in/contains`。
- 非法规则丢弃，未知上下文按“规则满足”保守处理；摘要数值字段仅用于 BOQ 审批链路，商务标审批沿用旧三字段上下文，审批记录仍写原链索引。
- 前端审批链弹窗支持规则配置、归一化与生效级展示；项目 PATCH 回显规则，真实 DB 集成覆盖 `version_payload`、`review_version`、`pending_for_user` 与错审批人拒绝。
