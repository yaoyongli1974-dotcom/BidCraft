# BidCraft v0.6.4

管理侧可观测性补齐：超管能看到服务真实的运行状态，而公开探针仍然什么都问不出来。

## 本版内容

- **`GET /admin/health`（超管）**：返回版本号、进程 uptime、磁盘占用与关键对象计数，供运维
  判断「服务还活着吗、是哪个版本、库有多大」。需管理员会话。
- **公开 `/health` 保持最小化**：仍只回一个轻量存活信号，不泄露版本、路径与计数，避免成为
  未授权探测入口。
- **README 补充实测案例**：一份 41,097 字的投标文件，导出 80 页 A4，13 次模型请求，
  102,150 tokens，约 ¥0.28，给「成本到底多少」一个可核对的锚点。
- 测试：新增暴露面用例，确保 `/admin/health` 无会话时不可读、`/health` 不回归成信息出口。

## 验证

- 后端：全量 pytest 通过，ruff 全绿。
