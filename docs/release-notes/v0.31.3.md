# v0.31.3 发版说明（生产上线前验收准备）

**主题：生产上线前最后验收与风险收口——真实 PostgreSQL 并发、八类 Worker 运行时、文件副作用、指标口径、迁移权限与 CI/容器门禁**

本版本是 v0.31.2 之后的生产上线前专项验收，所有改动在独立分支 `fix/v0.31.3-production-readiness` 上按阶段提交。遵循「先复现、再修复」：先在真实 PostgreSQL 上复现退款布尔比较缺陷，再修改生产代码；SQLite 通过不等同 PostgreSQL 通过，源码检查不作为运行时证据，合成招标文件不冒充真实样本。

## 1. 真实 PostgreSQL 并发（阶段 1）

- 用 pgserver 启动真实 PostgreSQL 16.2，覆盖 100 轮 Reaper/心跳竞争、100 轮终态提交竞争、50 轮上限退款与 50 轮 settle/reconcile。
- 复现并修复生产缺陷：`refund_charged_job()` 中 `refund_claimed == 0` 在 PG BOOLEAN 列上生成 `boolean = integer`，导致退款失败；改为 `.is_(False)`，SQLite 与 PG 均兼容。
- 修正金额口径断言：charged=6、chapters=3、done=1  earned=2、退款 4，余额 98（未放宽断言）。

## 2. 八类 Worker 运行时（阶段 2）

- 动态发现 8 类 runner，在真实 PG Job/JobEvent 上验证旧 token、取消任务不复活、预置 abort、过期 lease、正常终态唯一、重复终态幂等与终态写入异常回滚，共 57 项。

## 3. 文件副作用与质量口径（阶段 3～4）

- 修复导出归档在 fencing 失败后残留部分 ZIP 的问题：失败路径删除临时归档，成功路径保留；DB 回滚不宣称会回滚文件系统。
- 图片已生成资产在租约失效后保留，重试命中 `status=ready` 跳过；KB 索引仅写 DB。
- 真实 PG 上验证项目指标分母与真实件数据集口径：缺数据集/合成标记均保持「未测量」，标注样本下 clause_recall / value_parse_rate / verdict_agreement 均为 1.0。

## 4. 迁移与权限（阶段 5）

- 真实 PG 上完成 `head → 0001_baseline → head` 往返，验证列、索引、表、数据与版本号恢复。
- 验证成员角色过滤、`_require_write` 403、跨项目 finding 查询与 PATCH 均为 404，无跨项目审计污染。

## 5. CI / 容器门禁（阶段 6）

- 修复 `tests/postgres/conftest.py` 级 `pytestmark` 不生效的问题：无 PG URL 时由 fixture 显式 skip，消除 67 个 ERROR。
- CI PostgreSQL job 现在运行全部 `tests/postgres/**` 及既有 PG 套件，并断言 `tests >= 900 / skipped == 0 / failures == 0`；安装 postgresql-client。
- 安全审计/Bandit/密钥扫描移除 `continue-on-error`，npm full-tree 审计不再 `|| true`。
- docker-image job 增加真实容器启动与 `/health/live` 轮询；compose 显式透传生产环境变量（保留无 `env_file` 决定）。

## 6. 兼容性

- 无新增迁移，Alembic 单 head 仍为 `0012_generation_lease`；历史迁移 0001～0012 零改动。
- API 路由数量与业务语义不变；版本 0.31.3 同步后端、前端与部署清单。
- 生产唯一代码修复为 `refund_charged_job` 的布尔比较；其余为测试、CI、文档与文件清理修复。

## 8. 边界与结论

- pgserver 是真实 PostgreSQL 但不是生产实例；CI 使用 `postgres:16-alpine` 覆盖相同路径。
- Docker 运行时健康检查本地未验证（无 Docker），由 CI docker-image job 覆盖。
- 真实脱敏招标文件仍需用户提供；在此之前真实件指标保持「未测量」。
- 本分支未推送 main、未创建 tag/Release、未部署生产；是否满足上线条件以 `docs/development/BIDCRAFT_V0313_FINAL_ACCEPTANCE_REPORT.md` 的四类结论为准。
