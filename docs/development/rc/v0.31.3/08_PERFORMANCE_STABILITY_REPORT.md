# G7 性能、并发与稳定性报告（RC v0.31.3）

## 1. 环境

- 隔离 RC home：`/tmp/opencode/rc-v0313-home`
- 数据库：RC 专用 PostgreSQL 16.2（pgserver，TCP `127.0.0.1:5432`），URI 仅用于本脚本，报告中不记录口令
- 运行方式：`TestClient(create_app())`，登录令牌来自 RC 测试账号（口令由环境文件读取，不打印）
- 数据：RC 自建测试数据；未访问生产库、未使用真实客户数据

## 2. 实测结果

| 场景 | 次数 | 结果 | P50 | P95 / MAX |
|---|---:|---|---:|---|
| `GET /projects` | 300 | 全部 200 | 14.16 ms | P95 15.45 ms / MAX 188.4 ms |
| `POST /projects` | 30 | 全部 201 | 73.33 ms | MAX 159.12 ms |
| `GET /health/live` | 100 | 全部 200 | 6.25 ms | — |
| 登录 | 1 | 200 | — | — |

单次冷启动/首请求抖动体现在 `MAX 188.4 ms`，后续绝大多数请求稳定在 15 ms 左右；建项目包含数据库写入，P50 73 ms 属可接受范围。

## 3. 并发与稳定性证据

G5 的真实 PostgreSQL 并发/恢复测试共 **561 passed / 40.95s**，覆盖：

- 8 类 runner 的旧 token、取消任务、预置 abort、过期租约、终态唯一写入、重复终态幂等、写入异常回滚；
- Reaper 与 Worker 的租约竞争、重试上限退款、NULL/过期租约终态拒绝；
- 导出 zip 失败清理、成功保留；图片重试幂等；知识库 DB-only 写入。

本轮性能脚本未观察到 5xx、连接泄漏或状态漂移；上述 561 项并发用例全部通过。

## 4. 状态与残余风险

- **A PASS**：隔离 RC 环境下的轻量吞吐、健康探针与 G5 并发稳定性。
- **NOT VERIFIED**：生产规模数据量、真实模型长任务、真实外部文件/对象存储与生产告警阈值；本轮未连接生产环境，也未做长时间 soak。
- 假模型地址 `http://127.0.0.1:9/v1` 只用于启动校验，不代表模型调用质量；生成质量在 G8 RC 样本环节单独说明（无真实模型时仍为 NOT VERIFIED）。
