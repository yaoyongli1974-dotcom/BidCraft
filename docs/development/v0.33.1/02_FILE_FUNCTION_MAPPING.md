## 跨阶段约束

- 不重复造系统：所有改动复用表中已有 helper（explain、releasable filter、dataset/benchmark/ratings loader、lesson_items、continuity_digest、redact/tool loop、jobqueue 条件 UPDATE、backup）。
- 最难契约点：P1 必须同时更新两个 pending 精确键测试，避免“后端新增字段但测试仍锁死旧 shape”。
- 数据阻塞不可由代码实现关闭：真实招标件、qrels、专家评分均仅有示例 manifest，真实 `dataset.json` 被 gitignore。
- 证据型缺口：生产等价 PG/PgBouncer、真实模型、恢复演练为新 SHA 验收证据，不得写成已验证。
